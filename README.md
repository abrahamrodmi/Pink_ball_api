El sistema a partir de un dataset de imagenes de Jigglypuff, Kirby, Wigglytuff y otro  conjunto de imagenes aleatorias para la clase Otro; se preprocesa las imagenes con la funcion HOF. Posteriormente, se entrenan los datos con un algoritmo KNN para detectar si una imagen de entrada pertenence a alguno de los tres con base en su forma y contorno. Se desarrolla una API para facilitar el ingreso y carga de imagen por parte del usuario.
